# Collection Sources

## Primary structured source

- [Kanade karaoke set lists - Setlist Index](https://setlist.kibunya.org/channel/@OtonoseKanade/)

Setlist Index is the primary structured source when it has a matching broadcast entry. Its title, date, song order, artist, and timestamp fields are imported as source-confirmed candidates while preserving the original source URL.

## Verification and fallback sources

- [Otonose Kanade - Holodex channel](https://holodex.net/channel/UCWQtYtq9EOB4-I5P-3fh8lA)
- [Holodex singing search](https://holodex.net/search?q=type%2Cvalue%2Ctext%0Achannel%2CUCWQtYtq9EOB4-I5P-3fh8lA%2CKanade%20Ch.%20%E9%9F%B3%E4%B9%83%E7%80%AC%E5%A5%8F%20%E2%80%90%20ReGLOSS%0Atopic%2Csinging%2Csinging)
- [Kanade Official Songs/Covers - Musicdex](https://music.holodex.net/playlists/DTzQMI1M46/)

Use Holodex comments and the broadcast timeline to resolve missing, conflicting, or suspicious Setlist Index entries. Musicdex helps find related official and cover songs but does not automatically override broadcast evidence.
