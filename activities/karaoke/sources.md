# Collection Sources

## Primary structured source

- [Kanade karaoke set lists - Setlist Index](https://setlist.kibunya.org/channel/@OtonoseKanade/)

Setlist Index is the source of record for matching Kanade karaoke broadcasts. Its title, date, song order, artist, and timestamp fields are imported as source-confirmed values while preserving the original displayed text and source URL.

## Related source for future playlist mapping

- [Kanade Official Songs/Covers - Musicdex](https://music.holodex.net/playlists/DTzQMI1M46/)

Musicdex may help locate official songs and covers for the separate original-song mapping task. It does not replace the Setlist Index broadcast data.
